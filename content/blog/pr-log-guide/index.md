修复日志和公告现在可以全自动记录了：不需要手动在 `content/log/` 下新建文件，只要在 PR 上打个标签。

## 怎么用

1. 发起 Pull Request
2. 在 PR 上添加 `log` 标签
3. 合并进 `main` 后，CI 会自动：
   - 用 PR 标题生成日志标题
   - 用 PR 描述的第一段生成日志摘要
   - 在 `content/log/pr-<编号>/` 下生成日志条目并推回仓库
   - 重新部署站点

完成后就能在[日志栏](/log/)看到这条记录了。

## 注意事项

- 不想记录到日志栏的 PR 不要打 `log` 标签
- PR 描述的第一段会被用作日志摘要，建议写清楚本次改动的要点
- 生成的日志条目会自动附带来源 PR 链接
- 也可以手动在 `content/log/` 下写日志条目，必填 `title` / `summary`，`date` 会自动按首次提交时间填写
