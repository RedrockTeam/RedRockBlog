# 为博客新增编辑与写新文章入口

## 改动内容
- 博客文章底部新增「编辑本页」链接，跳转到该文章对应的 GitHub 在线编辑页面，blog section 默认全部可编辑
- 博客列表页新增「写新文章」按钮，跳转到 GitHub 新建文件页面并预填文件名为 `new/index.md`
- 新增 `hugoblox.repository` 配置项，供主题拼接编辑与新建 URL
